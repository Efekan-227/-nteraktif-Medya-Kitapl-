# İnteraktif Medya Kitaplığı

Bu proje, Sakarya Üniversitesi ISE-201 Web Teknolojileri dersi kapsamında geliştirilmiş bir **Single Page Application (SPA)** medya kitaplığı uygulamasıdır. Kullanıcılar; film, dizi ve kitapları listeleyebilir, gelişmiş filtreleme seçeneklerini kullanabilir ve favori listelerini yönetebilirler.

## 🚀 Proje Özellikleri
- **Single Page Application (SPA):** Sayfa yenilenmeden dinamik içerik yönetimi.
- **Gelişmiş Filtreleme:** Kategoriye (Film, Dizi, Kitap), yönetmen/yazara ve yıla göre filtreleme; puana göre sıralama.
- **Favori Sistemi:** Tarayıcı tabanlı `localStorage` kullanarak kişisel favori listesi oluşturma.
- **Duyarlı Tasarım (RWD):** Mobil, tablet ve masaüstü cihazlarla tam uyumlu arayüz.
- **Modern Teknikler:** Anlamsal (Semantic) HTML5 etiketleri ve CSS Grid/Flexbox mimarisi.

## 🛠️ Kullanılan Teknolojiler
- **HTML5:** Yapısal ve anlamsal işaretleme.
- **CSS3:** Modern grid sistemi ve geçiş animasyonları.
- **JavaScript (ES6+):** Fetch API, Async/Await ve DOM manipülasyonu.
- **Veri Yönetimi:** Yerel JSON dosyası üzerinden asenkron veri çekme.

## 📂 Dosya Yapısı
- `index.html`: Uygulamanın ana iskeleti.
- `style.css`: Modern ve duyarlı stil tanımlamaları.
- `app.js`: Uygulama mantığı ve SPA yönlendirmeleri .
- `data.json`: Medya verilerini içeren yerel veritabanı.
- `img/`: Medya kapak görsellerinin bulunduğu klasör.

## 📋 Kurulum ve Çalıştırma
1. Bu depoyu (repository) bilgisayarınıza klonlayın.
2. Herhangi bir modern web tarayıcısı ile `index.html` dosyasını açın.
3. Veya  üzerinden canlı demoyu inceleyin.
